# MediaPipe Pose and Curl Counting

Use a local desktop session with an available webcam and Python 3.11. Run the camera cells individually and press q in the preview window to stop each demo. The notebook explores pose and hand landmarks, elbow angles, and curl counting.

Notebooks: [mediapipe-curl-counter.ipynb](mediapipe-curl-counter.ipynb)

From this directory, use a fresh Python 3.11 environment:

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```
